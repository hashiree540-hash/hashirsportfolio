## 🚀 How to Run & View

### Option A: Direct Open (Zero installation required)
Simply double-click `index.html` to open the portfolio immediately in any web browser.

### Option B: Local Development Server with Vite
```bash
npm install
npm run dev
```

### Option C: Production Build
```bash
npm run build
npm run preview
```
